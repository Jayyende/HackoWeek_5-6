# Matrices

## Definition

A matrix is a rectangular arrangement of numbers in rows and columns.

Example:

|1 2|
|3 4|

This is a 2×2 matrix.

## Applications

- Image Processing
- Neural Networks
- Data Representation

## Matrix Addition

A = |1 2|
    |3 4|

B = |5 6|
    |7 8|

A + B =

|6 8|
|10 12|

## Conclusion

Matrices help store and process large amounts of data efficiently.
