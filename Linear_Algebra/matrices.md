# Matrices

## Introduction

A matrix is a rectangular arrangement of numbers organized into rows and columns. Matrices are fundamental in linear algebra and are extensively used in machine learning, data science, computer graphics, and scientific computing.

Example:

A =

|1 2|
|3 4|

This matrix contains 2 rows and 2 columns.

---

## Types of Matrices

### Row Matrix

Contains only one row.

Example:

[1 2 3]

### Column Matrix

Contains only one column.

Example:

|1|
|2|
|3|

### Square Matrix

Rows = Columns

Example:

|1 2|
|3 4|

### Identity Matrix

A matrix whose diagonal elements are 1 and all others are 0.

Example:

|1 0|
|0 1|

### Diagonal Matrix

Only diagonal elements contain non-zero values.

---

## Matrix Operations

### Addition

Matrices of the same size can be added.

### Subtraction

Matrices of the same size can be subtracted.

### Multiplication

Rows of the first matrix are multiplied by columns of the second matrix.

### Transpose

Rows become columns.

## Importance in Machine Learning

Datasets are usually stored in matrix form.

Example:

|Age|Study Hours|Marks|
|---|---|---|
|20|4|50|
|21|5|60|
|22|6|70|

Almost every machine learning algorithm performs matrix operations internally.

---

## Conclusion

Matrices provide an efficient way to store and manipulate large amounts of numerical data.
