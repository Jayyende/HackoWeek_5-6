# Vectors

## Definition

A vector is an ordered collection of numbers that represents magnitude and direction.

Example:

Vector A = [2, 3]

This means:
- 2 units along x-axis
- 3 units along y-axis

## Applications

- Machine Learning
- Computer Graphics
- Robotics
- Data Science

## Example

Vector = [3, 4]

Magnitude:

√(3² + 4²)

= √25

= 5

## Conclusion

Vectors are used to represent data and directions in mathematics and AI.
