# Vectors

## Introduction

A vector is a mathematical object that represents both magnitude and direction. In machine learning, vectors are used to represent data points, features, images, text embeddings, and model parameters.

A vector is usually represented as an ordered list of numbers.

Example:

v = [2, 3]

This vector has two components: 2 and 3.

---

## Types of Vectors

### 1. Row Vector

A vector written horizontally.

Example:

[1 2 3]

### 2. Column Vector

A vector written vertically.

Example:

[1]
[2]
[3]

### 3. Zero Vector

A vector whose elements are all zero.

Example:

[0 0 0]

### 4. Unit Vector

A vector with magnitude equal to 1.

Example:

[1,0]

---

## Magnitude of a Vector

The magnitude represents the length of the vector.

Formula:

|v| = √(x² + y²)

Example:

v = [3,4]

|v| = √(3² + 4²)

|v| = √25

|v| = 5

---

## Vector Operations

### Vector Addition

A = [1,2]

B = [3,4]

A + B = [4,6]

### Vector Subtraction

A - B = [-2,-2]

### Scalar Multiplication

2 × [1,2]

= [2,4]

## Importance in Machine Learning

Every dataset in machine learning can be represented as vectors.

Example:

Student Data:

[Age, Study Hours, Attendance]

[20, 5, 90]

This entire row is a vector.

Vectors help machine learning models process numerical information efficiently.

Vectors form the foundation of linear algebra and machine learning. They are used to represent data, model parameters, and multidimensional information.
